## 软件简介

**AutoTestGUI** 是一款 Windows 自动化测试工具，用于录制用户的鼠标和键盘操作，并支持回放执行。

### 主要应用场景
- 软件功能测试
- 重复性操作自动化
- 批量数据录入
- 界面截图采集

---

## 安装与启动

### 系统要求
- Windows 10/11
- Python 3.9+ (如运行源码)
- 管理员权限（首次运行会自动申请）

### 启动方式
1. **直接运行**：双击 `AutoTestGUI_V2.xx.exe`
2. **源码运行**：`python auto_test_gui.py`

> ⚠️ 首次运行会申请管理员权限，这是正常的安全机制。

## 快速开始

### 录制第一个动作

1. 点击 **「录制」** 按钮（或按 `Ctrl+Shift+L`）
2. 状态显示「正在录制...」
3. 执行你要录制的操作（点击、输入等）
4. 点击 **「停止录制」**（或按 `Esc`）

### 回放动作

1. 点击 **「回放」** 按钮（或按 `Ctrl+Shift+P`）
2. 工具会按顺序执行所有录制的动作
3. 按 `Esc` 可随时停止回放

## 动作类型详解

| 动作类型 | 说明 | 延时说明 |
|---------|------|---------|
| `click` | 单击 | 动作前等待 delay 时间 |
| `doubleclick` | 双击 | 动作前等待 delay 时间 |
| `move` | 移动鼠标 | 动作前等待 delay 时间 |
| `input` | 文本输入 | 动作前等待 delay 时间 |
| `keyboard` | 键盘按键 | 动作前等待 delay 时间 |
| `scroll` | 滚轮滚动 | 动作前等待 delay 时间 |
| `delay` | 纯延时 | 直接等待指定时间 |
| `screenshot` | 截屏 | 执行截屏操作 |
| `traverse_input` | 序列输入 | 循环输入递增/递减数值 |

### 1. 单击/双击 (click/doubleclick)
- **录制**：点击鼠标时自动记录
- **参数**：坐标 (x, y)、按钮类型 (left/right/middle)
- **延时**：点击前等待 `delay` 秒

### 2. 移动 (move)
- **录制**：鼠标移动超过阈值时记录
- **参数**：目标坐标 (x, y)
- **注意**：如紧跟点击动作，会合并移动过程

### 3. 文本输入 (input)
- **录制**：点击输入框并输入文本时记录
- **参数**：坐标、输入文本
- **执行**：点击目标位置 → 全选 → 删除 → 输入文本

### 4. 键盘按键 (keyboard)
- **录制**：按下键盘按键时记录
- **参数**：按键列表
- **支持**：单键、组合键 (如 Ctrl+C)

### 5. 滚轮滚动 (scroll)
- **录制**：滚动鼠标滚轮时记录
- **参数**：坐标、滚动量 (dx, dy)

### 6. 延时动作 (delay)
- **添加方式**：点击「添加延时」按钮
- **参数**：延时时长（秒）
- **执行**：等待指定时间

### 7. 截屏 (screenshot)
- **添加方式**：点击「添加截屏」按钮
- **参数**：保存目录、文件名、命名方式
- **命名方式**：
  - `timestamp`：使用时间戳命名
  - `sequence`：使用序号命名

### 8. 序列输入 (traverse_input)
- **添加方式**：点击「添加序列输入」按钮
- **参数**：
  - 起始值、结束值、步长
  - 模板格式（如 `{n}` 或 `text_{n}`)
- **示例**：起始 1，结束 10，步长 1，模板 `item_{n}`
  - 生成：item_1, item_2, ..., item_10

## 循环组功能

循环组可以将一组动作重复执行多次。

### 创建循环组

1. 选择动作列表中的一个或多个动作
2. 点击 **「创建循环组」** 按钮
3. 配置循环参数：
   - **循环次数**：重复执行次数
   - **间隔类型**：
     - 固定间隔：每次循环后等待相同时间
     - 随机间隔：在最小/最大之间随机等待
     - 等差间隔：每次循环后等待时间递增
     - 倍数间隔：等待时间 = 基数 × 循环序号

### 循环组内动作编辑

在循环组内，可以：
- **添加动作**：在循环组内录制新动作
- **编辑动作**：双击动作修改参数
- **删除动作**：选中后按 Delete 键

### 循环间隔类型详解

| 类型 | 说明 | 示例 |
|-----|------|------|
| 固定 | 每次等待相同时间 | 间隔=1.0s，循环3次：每次间隔1s |
| 随机 | 每次等待随机时间 | 范围0.5~2.0s，每次随机 |
| 等差 | 等待时间递增 | 起始1s，步长0.5s：1s, 1.5s, 2s... |
| 倍数 | 等待时间=基数×序号 | 基数1.0s：第1次1s, 第2次2s, 第3次3s |

## 延时设置

### 动作延时
- 每个动作的 `delay` 字段表示**动作执行前**等待的时间
- 例如：delay=0.2 表示等待0.2秒后再执行该动作

### 默认延时设置
在界面底部可设置：
- **默认延时范围**：录制新动作时自动应用
- **最小延时** / **最大延时**：随机延时模式

### 延时类型动作
- `delay`：固定延时
- `random_delay`：随机延时
- `multiply_delay`：倍数延时
- `arithmetic_delay`：等差延时

## 文件管理

### 保存动作
1. 点击 **「保存」** 按钮
2. 选择保存位置
3. 输入文件名（.json）
4. 动作保存为 JSON 格式

### 加载动作
1. 点击 **「加载」** 按钮
2. 选择之前保存的 .json 文件
3. 动作列表会自动更新

### 文件格式示例

V2.42 起，动作文件除动作列表外，**还会保存主界面的循环设置**（次数、间隔、随机开关、随机范围），
加载时自动恢复到界面。

```json
{
  "version": 2,
  "settings": {
    "loop_count": 5,
    "loop_interval": 1.5,
    "interval_random": false,
    "interval_min": 0.5,
    "interval_max": 1.5
  },
  "actions": [
    {
      "type": "click",
      "x": 100,
      "y": 200,
      "button": "left",
      "delay": 0.2,
      "remark": "点击确定按钮"
    },
    {
      "type": "input",
      "x": 150,
      "y": 250,
      "text": "Hello World",
      "delay": 0.5
    }
  ]
}
```

> ℹ️ **兼容旧格式**：V2.42 之前保存的文件是纯动作数组（`[...]`），
> 仍然可以正常加载，只是不会覆盖当前界面的循环设置。

## 故障排除

### 问题：点击位置与录制位置不一致
**原因**：多显示器环境下坐标系统可能不一致
**解决**：
- 确保主显示器在左侧
- 扩展屏录制后在主屏回放可能有问题（已知问题）

### 问题：回放时窗口失去焦点
**原因**：自动化操作需要目标窗口在前台
**解决**：
- 点击目标应用窗口后再开始回放
- 确保目标窗口未被最小化

### 问题：录制时点击了工具自身
**解决**：
- 工具会自动识别自身窗口并跳过记录
- 或在录制前将工具窗口移开

### 问题：输入动作无法正确输入
**解决**：
- 部分应用对自动化输入有限制
- 尝试使用键盘按键动作替代
