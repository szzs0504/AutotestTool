# 自动测试工具

一个基于 Python Tkinter 的自动化测试 GUI 应用程序，支持录制鼠标和键盘操作，并可回放执行。

## 功能特性

### 录制功能
- **鼠标录制**：支持单击、双击、滚轮滚动操作
- **键盘录制**：支持单键和组合键（如 Ctrl+C, Alt+Tab）
- **移动录制**：可选是否记录鼠标移动轨迹
- **点击录制**：手动插入点击坐标，支持延时设置

### 动作类型
- **点击/双击**：录制鼠标点击位置和按钮
- **移动**：录制鼠标移动轨迹
- **滚动**：录制滚轮操作
- **按键**：录制键盘按键和组合键
- **延时**：支持多种延时类型
  - 随机延时：最小~最大范围随机延时
  - 倍数延时：每轮循环延时倍增
  - 等差递增：每轮循环延时递增
- **变量输入**：支持变量递增的文本输入（如 text0, text1, text2...）
- **截屏**：自动截取屏幕截图
- **循环组**：将多个动作放入循环组中执行

### 编辑功能
- **双击编辑**：所有动作均可双击编辑
  - 点击动作：编辑坐标、重新录制位置、修改延时
  - 延时动作：修改延时参数
  - 变量输入：编辑输入内容和变量参数
  - 循环组：编辑循环次数和间隔
- **内联编辑**：双击延时列可快速修改延时
- **备注编辑**：双击备注列可添加/修改备注

### 循环组
- 支持多层嵌套循环组
- 树形结构显示，直观展示层级关系
- 缩进显示父级与子级关系

### 其他
- **快捷键支持**：
  - `Ctrl+Shift+R`：开始/停止录制
  - `Ctrl+Shift+P`：开始回放
  - `Ctrl+Shift+S`：停止回放
  - `Ctrl+Q`：强制停止回放
- **脚本保存/加载**：支持保存和加载动作脚本
- **弹窗保护**：在对话框操作时自动停止录制

## 使用方法

1. 运行程序（需要管理员权限）
2. 点击"录制"按钮或使用快捷键 `Ctrl+Shift+R` 开始录制
3. 执行需要自动化的操作
4. 再次点击"录制"按钮停止录制
5. 点击"回放"按钮或使用快捷键 `Ctrl+Shift+P` 执行录制

## 界面说明

- **左侧按钮区**：插入各种动作（点击、延时、循环组、变量输入、截屏等）
- **中间动作列表**：显示所有录制的动作，支持双击编辑
- **右侧控制区**：录制/回放控制、快捷操作按钮
- **底部状态栏**：显示当前状态和快捷键提示

## 注意事项

- 需要以管理员权限运行以确保UI自动化功能正常工作
- 在对话框（延时、循环组、变量输入等）中进行操作时不会录制动作
- 循环组内的动作支持多层嵌套
